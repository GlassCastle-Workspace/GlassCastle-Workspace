SUPPORT

Secret Tunnel failures are easiest to solve from the boundary inward: device availability → pairing → grant → local sensor enable → observation.

Connection checklist

  1. Confirm the Secret Tunnel device or gateway is online.
  2. Confirm the intended device profile is paired.
  3. Use the perception catalog to confirm the device actually advertises the requested sensor.
  4. Confirm the Sec-TP identity has the individual capability grant.
  5. For screen, camera, microphone, or precise location, confirm the device owner has locally enabled that personal sensor.

Security boundary

Do not send private keys, pairing tokens, passwords, authentication cookies, or other credentials in a support request. Secret Tunnel support should not need those secrets.

Contact

For support or responsible security reports, contact glasscastles@proton.me. Include the Secret Tunnel version, operating system, affected capability name, and a redacted error message. Do not include sensor payloads unless they are necessary to reproduce the issue.
