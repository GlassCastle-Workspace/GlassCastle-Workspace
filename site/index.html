02B // INTRUSION RELATIONSHIP LENS

DIAMOND MODEL OF INTRUSION ANALYSIS

An event relates Adversary, Infrastructure, Capability, and Victim. Missing features remain knowledge gaps. Confidence stays attached to supplied evidence. Diamond Phase can reference explicit UKC phases without collapsing the two models.

COREADVERSARYoften unknown
COREINFRASTRUCTUREphysical / logical
CORECAPABILITYtools / techniques
COREVICTIMpersona + assets
EVENTTimestamp · Phase · ResultDirection · Methodology · Resources
EXTENDED AXISSOCIAL-POLITICAL

Adversary ↔ Victim needs, intent, persistence, and victimology. Never inferred from technical overlap alone.

EXTENDED AXISTECHNOLOGY

Capability ↔ Infrastructure enabling technologies such as protocols, platforms, and communication mechanisms.

ANALYTIC RULEUNKNOWN = KNOWLEDGE GAP

Pivot from known features to possible connected evidence. A possible pivot is not a successful pivot, attribution, or causal proof.
