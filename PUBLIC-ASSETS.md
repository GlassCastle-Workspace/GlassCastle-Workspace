## Brand system

- Public display name: **GlassCastle(s)**
- Core promise: **Security Through Visibility.**
- Principle: **Evidence before assertion. Visibility before assumption.**
- Type: **Roboto Mono**
- Foundation: void black / near-black
- Primary signal: emerald `#35ff95`
- Boundary / analytical accent: violet `#9a6cff`

The brand should feel inspectable rather than theatrical: high legibility, explicit boundaries, restrained glow, topology, traces, relationships, and provenance.

## Deliberately not public

Internal operations, finance, human-relations, control-plane, private Secret Tunnel repositories, local runtime state, deployment identifiers, secrets, `.env` files, receipts, and infrastructure details are not part of the public surface.

Public availability is not permission. Publication is exposure, not demand.
